# 동영상 구간 자르기

## 사용자 동작

타임라인에서 동영상이나 Live Photo 클립을 선택하고 **자르기**를 누른다. iPhone 사진 앱처럼 프레임 띠의 왼쪽 끝을 끌어 시작점을, 오른쪽 끝을 끌어 끝점을 정한다. **완료**를 누르면 필름에는 그 사이의 영상과 음성만 들어간다. Live Photo는 내부 영상의 구간을 사용하고, 사진 보관함의 원본은 보존한다. [Apple 사진 앱의 동영상 자르기](https://support.apple.com/guide/iphone/trim-video-length-adjust-speed-and-edit-audio-iph1d1344a2d/ios)

같은 영상에서 두 장면을 쓰려면 첫 구간을 **완료**로 적용한다. **자르기**를 다시 열어 두 번째 구간을 정한 뒤 **새 클립으로 추가**를 누르면 바로 다음 칸에 새 클립이 들어가고 선택된다. 각 클립에서 원본의 전체 길이를 기준으로 자르기 구간을 다시 조정할 수 있다.

## 필수 기능

| 상황 | 기대 동작 |
| --- | --- |
| 편집 시작 | 타임라인에서 영상 파일과 재생 시간을 확인한 동영상 및 Live Photo에 자르기 도구를 표시한다. 타임라인 재생을 멈추고 해당 클립을 연다. 영상 파일이나 원본 길이가 없는 클립에서는 도구를 숨긴다. |
| 처음 열기와 다시 열기 | 처음에는 원본 전체를 선택한다. 다시 열면 직전에 적용한 구간이 선택되며, 양 끝을 바깥으로 다시 늘려 원래 길이까지 복구할 수 있다. |
| 시작점과 끝점 조정 | 시간순 썸네일 위에 두 핸들과 선택 테두리를 표시하고 제외 영역은 어둡게 한다. 움직인 핸들의 경계 프레임과 시작·끝·선택 길이를 즉시 갱신한다. 시간은 0.1초까지 표시한다. |
| 경계 제한 | 양 끝은 원본 안에 머물고 서로 교차하지 않는다. 기존 편집 정책대로 최소 선택 길이는 0.5초이며 그보다 짧은 원본은 전체 길이를 사용한다. |
| 재생 위치 | 프레임 띠에 현재 프레임을 가리키는 세로선과 잡을 수 있는 머리를 표시한다. 인디케이터를 끌면 선택 구간 안에서 해당 프레임을 바로 확인할 수 있다. 양끝에 겹쳐도 재생 위치와 자르기 핸들을 각각 조작할 수 있고, 재생 위치만 바꿔서는 선택 구간과 출력 영상이 바뀌지 않는다. VoiceOver에서는 재생 위치를 0.1초씩 조절할 수 있다. |
| 구간 미리보기 | 처음 열면 선택 시작점에 멈춰 있다. 재생하면 인디케이터 위치부터 원본 음성과 함께 재생하고, 세로선은 재생을 따라가다가 끝점에서 멈춘다. 일시정지 중 위치를 옮기면 다음 재생이 그 지점부터 시작한다. 재생 중 끌면 잠시 멈추고 손을 놓은 지점부터 이어서 재생한다. 끝점에서 재생을 다시 누르면 선택 시작점으로 돌아간다. 자르기 핸들을 움직이면 재생을 멈추고 옮긴 경계 프레임을 표시한다. |
| 완료와 취소 | 완료는 선택한 클립에만 구간을 적용한다. 취소는 편집에 들어가기 전 값을 복원한다. 원본 파일, 다른 클립, 기존 회전·화면 조정·자막을 보존한다. |
| 새 클립으로 추가 | 선택 구간을 현재 클립 바로 뒤에 삽입하고 선택한다. 두 클립은 같은 영상 파일을 사용하며 자르기, 화면 조정, 자막을 각각 관리한다. 새 클립은 현재 회전과 화면 구도로 시작하고 자막은 비워 둔다. |
| 타임라인과 내보내기 | 변경 직후 클립 길이, 전체 길이와 재생 위치를 갱신한다. 타임라인, 필름 내보내기, 보관함의 결과가 같은 구간을 사용한다. 재정렬 후에도 구간은 해당 클립을 따라간다. |
| 입력과 접근성 | 양쪽 핸들은 각각 독립된 VoiceOver 이름·현재 시간·0.1초 증감 동작을 제공한다. 좁은 화면과 가로 화면에서 두 핸들과 취소·완료에 접근할 수 있다. 한국어·영어·일본어 표시를 지원한다. |
| 펼친 iPhone Duo | 미리보기 아래에 재생 버튼과 선택 길이를 놓고, 프레임 띠를 하단의 좌우 가용 폭에 걸쳐 표시한다. 시작·끝 시각은 띠의 양 끝에 맞춘다. |
| 시스템 탐색 | 취소와 완료를 시스템 탐색 항목으로 제공한다. Duo를 펼쳐 가로로 사용할 때는 iOS가 정한 가장자리의 기본 세로 막대에 취소와 완료를 차례로 표시한다. 펼친 세로 화면에서는 시스템의 상단 가로 막대를 사용한다. 접거나 회전할 때 현재 선택 구간을 유지한다. |
| 원본 읽기 실패 | 편집기에서 원본을 읽을 수 없으면 오류를 표시하고 취소로 돌아갈 수 있다. 유효하지 않은 구간을 적용할 수 없다. |

## 인수 기준

1. 10초 영상에서 시작 2.0초, 끝 7.5초를 선택하면 선택 길이는 5.5초다. 미리보기와 출력 파일은 같은 원본 구간을 사용하며 앞 2초와 뒤 2.5초의 영상·음성이 제외된다.
2. 완료 후 다시 열어 양쪽을 늘릴 수 있고, 그 상태에서 취소하면 직전에 적용한 범위가 유지된다. 클립 재정렬과 다른 클립 편집 후에도 같은 결과가 나온다.
3. 한 핸들을 다른 핸들 너머로 끌거나 원본 바깥으로 끌어도 유효한 범위를 유지한다. 0.5초 미만인 영상은 길이를 늘리거나 줄이지 않는다.
4. 동영상과 Live Photo 모두 편집 후 타임라인에서 다음 클립으로 한 번만 전환하고, 필름 전체 길이는 각 클립에 적용된 구간 길이의 합과 일치한다.
5. 시뮬레이터에서 진입, 양쪽 드래그, 미리보기, 취소·완료, 재진입을 확인한다. 실제 미디어 기반 테스트로 내보낸 영상의 길이와 경계 콘텐츠를 확인한다.
6. 펼친 Duo에서 원본 전체 선택 시 두 핸들이 하단의 좌우 끝에 놓이고, 시스템 탐색 항목에서 취소와 완료를 각각 실행할 수 있다.
7. 2.0~7.5초 구간에서 일시정지한 인디케이터를 4.0초로 옮기면 4.0초 프레임이 보이고 재생도 4.0초부터 시작한다. 재생 중 다시 끌어도 놓은 위치에서 이어지며, 7.5초에서 멈춘다. 이 과정에서 양끝과 선택 길이 5.5초는 유지된다.
